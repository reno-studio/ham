操作與部署說明
  • 查詢優先使用 Data Matrix；空白時才使用資產編號，找到後填入資產編號、使用人、位置與備註。掃描成功後會自動進行相同查詢。
  • 綁定優先使用資產編號定位列，且 Data Matrix 或使用人至少需填一項；資產編號空白時，必須填入 Data Matrix，並在使用人、位置、備註中至少填一項。找到列時僅更新非空欄位；找不到列時新增一列。
  • 有填入的值會覆寫原值；空白欄位不會清除既有值。新增列會填入所有有內容的欄位；原有列不修改資產編號。輸入框會忽略前後空白，Data Matrix 則保留原始內容以供精確比對。
  • 若 Data Matrix 已屬於其他列，或查詢鍵重複，會停止並顯示錯誤。
  • 部署前請修改原始碼的 CLIENT_ID，填入有效的 Google OAuth「網頁應用程式」Client ID；原附件的值已遮蔽，無法直接登入。不需要 Client Secret。
  • 在同一 Google Cloud 專案啟用 Google Sheets API，設定 OAuth 同意畫面與測試使用者（若專案仍在測試模式），並將網站來源加入「已授權的 JavaScript 來源」。登入帳號須具有該試算表編輯權限。
  • 請透過 HTTPS 網站開啟；本機測試可用 http://localhost:8000，並將該來源加入 OAuth 設定。不要直接以 file:// 開啟。手機掃描請使用 HTTPS 並允許相機。
  • Access Token 僅存於本頁記憶體，重新整理或到期後需再次登入。每次查詢或綁定均重新讀取資料；多人同時寫入時仍應避免同時綁定相同識別碼或修改同一列。新增列只填入五個指定欄位，不自動複製其他欄的公式與格式。
